# เป้าหมายลูกค้า (Admin)

เมนู SalePro → เป้าหมายลูกค้า ใช้สิทธิ์ Admin เดิมของแอป

1. กดนำเข้ารายชื่อเริ่มต้น 15 ราย หรือเลือก CSV ตามไฟล์ตัวอย่าง (UTF-8, ไม่เกิน 200 ราย/500 KB)
2. ตรวจ preview แล้วกดยืนยัน ชื่อบริษัทและเบอร์ที่ซ้ำจะถูกข้าม รายชื่อยังไม่ได้รับการยืนยันว่ามี UPS หรือต้องการบริการ
3. เลือกราย บันทึกผู้ติดต่อ ข้อมูล UPS ผู้รับผิดชอบ ผลโทร สถานะ และวันติดตาม กดบันทึกทุกครั้ง
4. บันทึก Draft ได้โดยไม่เพิ่มลงทะเบียนลูกค้า หมายเหตุส่วนลดไม่มีผลคำนวณใบเสนอราคา
5. เมื่อพร้อม กดเพิ่มเข้า CRM ระบบตรวจชื่อและเบอร์กับ Customers ก่อนสร้าง และไม่คัดลอกส่วนลดไปเป็นส่วนลดที่อนุมัติแล้ว
6. กรณีไม่ให้ติดต่ออีก ให้เลือกสถานะนั้น ปุ่มโทรและสร้าง Draft จะถูกปิด

## ข้อมูลส่วนกลาง

ใช้ API เดิม อ่าน/เพิ่มแถวใน Settings ภายใต้คีย์ SalesProspectEvent_v1_ แต่ละการแก้ไขหรือผลโทรเก็บเป็น event ใหม่ พร้อมผู้บันทึกและเวลา ไม่แก้โครงสร้างชีต ไม่แก้ข้อมูล Role และไม่ใช้ localStorage เป็นฐานข้อมูลเป้าหมาย

ประวัติส่วนลดและการโทรยังอยู่ในหน้าเป้าหมายแม้เพิ่มเข้า CRM แล้ว ไม่ส่งข้อความ/อีเมลหรือโทรอัตโนมัติ วันติดตามเป็นตัวกรองในหน้า ไม่ใช่การแจ้งเตือนตามเวลา

สิทธิ์หน้าเว็บใช้ Admin guard เดิม ส่วนการเข้าถึง API ใช้การตรวจผู้ใช้งานของระบบหลังบ้านเดิม ไม่เพิ่มหรือขยายสิทธิ์บัญชีใด ระบบ API เดิมไม่ได้มี atomic compare-and-swap สำหรับหลายคำขอพร้อมกัน จึงมีการตรวจข้อมูลล่าสุดก่อนเขียนและตรวจซ้ำก่อนนำเข้า แต่ไม่รับประกันการป้องกันการสร้างซ้ำเมื่อหลายคนกดยืนยันในเวลาเดียวกัน ควรมอบหมายผู้รับผิดชอบนำเข้าทีละคน
