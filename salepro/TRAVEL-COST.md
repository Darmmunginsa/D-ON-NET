# ค่าเดินทางในใบเสนอราคา

Admin: Approve Settings → ตั้งค่าเดินทางนอกกรุงเทพฯ ระบุจุดเริ่มเดินทาง อัตราบาทต่อกิโลเมตร เที่ยวเดียวหรือไป–กลับ และเปิดใช้ ค่าบันทึกส่วนกลางใน Settings ชื่อ `TravelSettings_v1` ไม่กำหนดอัตราหรือที่อยู่แทนผู้ใช้งาน

Sales: สร้าง/แก้ไขใบเสนอราคา → ค่าเดินทางนอกกรุงเทพฯ ระบุที่อยู่หน้างานจริง เปิด Google Maps ตรวจเส้นทาง แล้วกรอกระยะทางขับรถ **เที่ยวเดียว** เลือกนอกกรุงเทพฯ และยืนยันระยะทาง เลือกรายการงานจำนวน 1 ที่ไม่มีส่วนลดรายรายการ แล้วกดคำนวณและรวมในราคางาน

ค่าเดินทาง = ระยะทางเที่ยวเดียว × อัตราต่อ กม. × จำนวนเที่ยว ปัด 2 ตำแหน่ง ไม่รวมทางด่วนหรือค่าใช้จ่ายอื่น หน้างานกรุงเทพฯ คิด 0 บาท ระบบไม่เดาจังหวัดหรือระยะทางจากข้อมูลที่ไม่ชัดเจน

ค่าเดินทางรวมในราคาต่อหน่วยของรายการที่เลือก **ก่อนส่วนลดรวมและ VAT** ไม่มีแถวค่าเดินทางใหม่ ทั้งยอดรายการ ยอดรวม ระดับอนุมัติ และ PDF ใช้ราคาที่รวมแล้ว กดคำนวณซ้ำไม่บวกทบ นำออกเพื่อคืนราคางานเดิมก่อนแก้จำนวน ราคา หรือส่วนลดรายรายการ

รายละเอียดคำนวณ/ราคาตั้งต้นเก็บเป็นข้อมูลภายใน `QuoteItemExtra_<id>` ของบรรทัดนั้น ไม่แสดงในเอกสารลูกค้า เมื่อสร้างใบใหม่จากใบเดิมหรือเก็บ Service Catalog จะใช้ราคางานก่อนรวมค่าเดินทาง ต้องคำนวณสำหรับหน้างานใหม่อีกครั้ง การเปลี่ยนอัตรา Admin ไม่มีผลย้อนหลังต่อราคาใบเดิม

## การเชื่อมแผนที่

รุ่นนี้เป็นการคำนวณเงินจากระยะทางที่ผู้ใช้ตรวจและกรอก ไม่ดึงระยะทางอัตโนมัติจาก Google การเชื่อม Routes API ยังไม่ได้เปิดใช้: ต้องมี Google Cloud ที่เปิด billing/API และเก็บ API key ที่เซิร์ฟเวอร์ พร้อมสิทธิ์เผยแพร่ backend ห้ามใส่ API key ในเว็บ static หรือ Settings ที่ผู้ใช้ทั่วไปอ่านได้ ไม่มีการสร้างระยะทางเส้นตรงมาแทนระยะขับรถ
